# 🔒 Encrypted Chat Application

A secure real-time chat application built with Python that enables encrypted communication between multiple users over a client-server architecture. The project uses AES encryption and PBKDF2-based key derivation to protect messages during transmission, ensuring privacy, confidentiality, and secure communication. It features a user-friendly GUI, multi-client support, active user tracking, timestamped messaging, and secure authentication mechanisms.

## Features
- Secure encrypted messaging using AES
- Multi-user real-time communication
- Client-server architecture
- User-friendly graphical interface (Tkinter)
- Active user monitoring
- Timestamped chat messages
- PBKDF2-HMAC-SHA256 key derivation
- Thread-based concurrent client handling

## Technologies Used
- Python
- Socket Programming
- Tkinter
- Cryptography Library
- Multithreading

## Purpose
This project demonstrates the practical implementation of cryptography, network security, and secure communication concepts while providing a foundation for developing privacy-focused messaging applications.
